# 🛍️ Kannan Shop — Modern E-Commerce Web Application

A responsive, user-friendly e-commerce web platform designed to provide a seamless online shopping experience. This project features dynamic product browsing, categorized product listings, an interactive shopping cart, and a responsive layout optimized for all devices.

---

## 📌 Features

- **Dynamic Product Catalog:** Display products with images, detailed descriptions, pricing, and category filters.
- **Interactive Shopping Cart:** Real-time cart calculations (add, remove, quantity adjustment, subtotal).
- **Responsive & Modern UI:** Mobile-first, fully responsive design ensuring compatibility across desktops, tablets, and mobile devices.
- **Search & Filter:** Quick product search and category-wise filtering for fast discovery.
- **Direct Ordering / Checkout Flow:** Streamlined checkout process with order summary and direct customer inquiry/contact integration.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (DOM Manipulation & Local Storage)
- **Styling:** Custom CSS / Modern Flexbox & Grid layouts
- **Deployment:** GitHub Pages / Netlify
